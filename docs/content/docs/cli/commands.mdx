## greet

Greet someone by name.

```bash
taste greet Alice
# Hello, Alice!

taste greet Alice --shout
# HELLO, ALICE!

taste greet Bob --shout --times 3
```

| Option | Short | Default | Description |
|--------|-------|---------|-------------|
| `--shout` | `-s` | `false` | Uppercase the greeting |
| `--times` | `-t` | `1` | Repetition count |

## config

Inspect and modify configuration.

```bash
taste config show                           # view full config
taste config get llm_config.cache_enabled   # get a single value
taste config set logging.verbose false      # set an override
```

| Subcommand | Description |
|------------|-------------|
| `show` | Display the full configuration |
| `get <key>` | Get a single value by dot-separated key |
| `set <key> <value>` | Write an override to `.global_config.yaml` |

## doctor

Run health checks on the project environment.

```bash
taste doctor          # check everything
taste doctor --fix    # auto-fix what it can
```

Checks Python version, `uv` installation, dependency sync, config validity, `.env` file, pre-commit hooks, and git status.

## init

Scaffold a new command from a built-in template.

```bash
taste init my_command --desc "Does something useful"
# Creates commands/my_command.py
# Run it: taste my-command
```

| Option | Description |
|--------|-------------|
| `--desc` | Description for the new command |

The name must be `snake_case`. Underscores are converted to hyphens for the CLI command name.

## completions

Install shell tab-completions for faster usage.

```bash
taste completions install bash    # append to ~/.bashrc
taste completions install zsh     # append to ~/.zshrc
taste completions install fish    # append to config.fish
taste completions show bash       # print script to stdout
```

## update

Check for a newer version and upgrade.

```bash
taste update
```

## telemetry

Manage anonymous usage telemetry.

```bash
taste telemetry status     # show enabled/disabled
taste telemetry disable    # opt out
taste telemetry enable     # opt back in
```

You can also set `CLI_TELEMETRY_DISABLED=1` to disable.
